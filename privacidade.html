Política de privacidade

Atualizada em 26/10/2026.

O que é o SaúdeSPX

O SaúdeSPX é um sistema interno de ficha de emergência. Ele ajuda quem presta o primeiro atendimento a encontrar, com rapidez, informações importantes de um colaborador (como alergias, tipo sanguíneo e contatos de emergência) e a registrar quem acompanhou o atendimento.

Quais dados usamos

  • Dados da sua conta Google: apenas o seu e-mail e o seu nome, enviados pelo Google quando você entra. Usamos para saber quem você é e se você tem acesso. Não temos acesso à sua senha, aos seus e-mails, arquivos, contatos ou agenda.
  • Pedido de acesso: o seu e-mail, o nome que você digitar e a data do pedido.
  • Registro de uso: quem abriu a ficha de quem, e quando. Serve para dar segurança a todos.
  • Fichas dos colaboradores: dados de saúde e de contato usados somente no atendimento de emergência. Só aparecem para pessoas que um responsável autorizou.

Para que usamos

Para liberar o acesso só a quem foi autorizado, para apoiar atendimentos de emergência e proteger a vida e a saúde das pessoas, e para manter um histórico de quem consultou cada ficha. Não usamos os dados para propaganda e não vendemos dados.

Quem pode ver

Quem entra mas ainda não foi aprovado não vê nenhuma ficha. Os responsáveis pelo sistema decidem quem pode apenas ler, quem pode editar e quem pode gerenciar os acessos, e podem retirar o acesso a qualquer momento.

Com quem os dados passam

Para funcionar, o sistema usa serviços de terceiros: o Google (para o login), o Supabase (banco de dados e controle de acesso) e a Vercel (hospedagem do site). Eles tratam os dados apenas para fazer o sistema funcionar.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O que fica no seu aparelho

Para você continuar logado, o navegador guarda no próprio aparelho os dados da sua sessão. Ao clicar em Sair, eles são apagados.

Por quanto tempo guardamos

Os dados de acesso ficam enquanto você tiver acesso ao sistema. Os pedidos e os registros de uso ficam como histórico de segurança. Os dados das fichas ficam enquanto forem necessários para o atendimento de emergência.

Seus direitos

Pela Lei Geral de Proteção de Dados (LGPD), você pode pedir para saber quais dados seus são tratados, corrigir dados errados e pedir a exclusão quando for cabível. Para isso, procure os responsáveis pelo sistema na sua empresa.

Mudanças nesta política

Se algo importante mudar, esta página será atualizada, com a nova data no topo.
